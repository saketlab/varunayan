varunayan

Climate data for India and beyond: ERA5, IMD, HadEX3 and CRU TS, filtered to a bounding box, GeoJSON or point, with heat stress indices (UTCI, WBGT, Heat Index, Humidex).

Python

pip install varunayan

Python package and command-line tool.

R

devtools::install_github("saketlab/varunayan", subdir = "R")

R package, with articles comparing ERA5 and IMD.

Live weather in your terminal

The Python package shows the most local reading available, and says what kind of reading it is and how old it is. With no place named, varunayan live uses your location, from your IP address.

$ pip install varunayan
$ varunayan live andheri
